# TIlProg
Vår hemsida är en hemsiada där man ska kommunicera via radiovågor. Vi utbyggde från vårt gym-arbete och tänkte att vi skulle göra något med radio.

## Beskrivning
Vårt projekt är en mottagarhemsida och en skrivapp där man ska kunna skicka meddelanden med hjälp av radiovågor. Vi valde att skapa en hemsida för att vi har jobbat med det på lektioner och vi valde att göra det med radiovågor är för att vi har jobbat med det på vårt gymnasiearbete.
Vår skrivapp och motagarhemsida funkar så att, med skrivappen skickas meddelandet, meddelandet skapas med skrivappen. Efter meddelandet är skapat så skickar användaren det, efter användaren har skickat det så tar motagarhemsidan upp det. När hemsidan har tagit upp meddelandet så skriver den ut det
i chattfältet.

När vi tänkte säkerhet tänkte vi på att i inloggningen skulle det vara svårt att veta om man han skrivit in rätt användarnamn eller lösenord, därför har vi gjort så att när man skriver in fel lösenord eller användarnamn kommer hemsidan säga att "Fel användarnamn eller lösenord".
Detta är bra eftersom  personen då inte vet vilket som är felet. 

En annan säkerhet vi har är att vi har två mappar för hemsidan och registreringen för att förhindra att folk kommer in på hemsidan direkt, vi har en Private mapp och en Public mapp. I Private-mappen ligger hemsidan som man bara kommer åt efter man har loggat in på sidan i Public-mappen.
I Public-mappen ligger Inloggningssidan och regristreringssidan som alla kommer åt.

## Kom igång
### Förutsättningar
* Visual studio code, node js och windows 10 eller senare.


### Installation (om möjligt)
* För visual studio code: Sök på visual studio codes i din sökmotor och ladda ner den senaste versionen.
* För Nodejs: Sök på NodeJs i din sökmotor och ladda ner den senaste versionen, även i visual studio code ska du ladda ett tillägg som heter "Node.js Modules Intellisense". Tillägg hittar du på vänstra sidan av visual studio code.
* Ett par kommandon du behöver köra i terminalen i visual studio code för att installera motorn är följande: Först "Bash" (sedan enter), sen "npm init -y" (sedan enter) och sist "npm install express express-session"(sedan enter).

### Köra programmet
* För att köra programmet:
* Först så måste du kolla så att du är i rätt mapp, vilken mapp du är i ser du i terminalen i visual studio code. Mappen du ska vara i är Server3, för att komma till rätt mapp skriver du "cd server3" som flyttar dig till rätt mapp.
* Därefter skriver du "node server.js"
* Efter det så skriver du in "localhost:3000" i din sökmotor tex chrome.
